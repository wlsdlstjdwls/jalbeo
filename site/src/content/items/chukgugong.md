공은 **바람을 빼고 종량제봉투입니다.** 축구공, 농구공, 배구공, 테니스공 다
같습니다. 고무와 가죽과 실이 한 덩어리라 재활용이 없습니다.

## 품목사전이 봉투로 둔 이유

환경부와 한국폐기물협회가 운영하는 분리의정석 품목사전은 축구공을 **일반폐기물**로
두고 이렇게 적습니다. <strong>"공은 고무, 플라스틱 등으로 제작되어 있으며,
접착제와 섬유재질이 혼합된 복합재질제품으로 재활용이 어렵습니다."</strong>
그리고 <strong>"공의 내부는 공기로 채워져 있어 배출, 수거하기에 어려움이 있으므로
가급적 제거한 후 배출하는 것이 좋습니다."</strong>

훈령 별표1 완구류 항목이 받는 것은 합성수지 완구이고 비해당품목에
<strong>"플라스틱 이외의 재질이 부착되어 분리할 수 없는 완구류"</strong>가
있습니다. 공은 안에 고무 튜브(블래더), 겉에 합성피혁, 그 사이에 실을 감은
구조라 여기 걸립니다.

## 바람을 빼는 이유

공기가 든 공은 봉투 안에서 자리를 차지하고, 수거차 압착판에 눌리면 터지면서
봉투를 찢습니다. 밸브에 공기 바늘을 꽂거나, 없으면 가는 송곳으로 밸브를 살짝
눌러 뺍니다. 반으로 접히면 됩니다.

## 종류별로

| 종류 | 배출 |
|---|---|
| 축구공, 농구공, 배구공 | 바람을 빼고 종량제봉투 |
| 야구공 | 종량제봉투. 실을 풀 필요 없습니다 |
| 테니스공 | 종량제봉투. 통(플라스틱)은 플라스틱류 |
| 골프공 | 종량제봉투 |
| 탁구공 | 종량제봉투 |
| 셔틀콕 | 종량제봉투 |
| 짐볼, 밸런스볼 | 바람을 빼서 종량제봉투. PVC라 플라스틱류가 아닙니다 |
| 볼풀공(플라스틱) | 속이 빈 단일 플라스틱이라 플라스틱류로 받는 곳이 있습니다. 지역 안내 확인 |
| 아이 고무공 | 종량제봉투 |
| 공 펌프 | 플라스틱과 금속. 종량제봉투 |

## 버리기 전에

- **바람만 빠진 공**은 펌프로 살립니다. 밸브가 새면 밸브 오일 한 방울로 고쳐지는
  경우가 많습니다
- **닳은 공**은 학교나 운동장 옆에 두고 가지 마세요. 그건 버린 게 아니라 무단투기입니다
- **테니스공**은 의자 다리 커버로 쓰는 사람이 있습니다. 나눔 카페에 올려 보세요
