부직포는 **종량제봉투입니다.** 천처럼 보여 의류수거함에 넣거나, 포장재라
비닐류에 넣는 경우가 많은데 둘 다 아닙니다. 섬유를 접착제로 굳혀 만든 합성
소재라 헌옷으로도 비닐로도 재생되지 않습니다.

## 천이 아니라 굳힌 섬유입니다

품목사전은 부직포 가방 항목에서 재질을 이렇게 설명합니다. <strong>"부직포란 섬유를
배열한 후 합성수지 접착제로 결합하여 펠트 모양으로 만든 제품으로 현재 대부분의
부직포는 합성섬유로 제작됩니다."</strong> 결론은 <strong>"합성섬유로 만든
부직포가방은 재활용이 어려우므로 종량제봉투로 배출합니다"</strong>이고, 유의사항이
<strong>"의류수거함에 배출 불가"</strong>입니다.

직물은 실을 짜서 만들지만 부직포는 짜지 않습니다(不織布). 폴리프로필렌이나
폴리에스터 섬유를 흩뿌려 열이나 접착제로 눌러 붙인 것입니다. 실로 풀리지 않으니
헌옷 재생 공정에 넣을 수 없고, 비닐처럼 녹여 성형할 수도 없습니다.

## 이런 것이 부직포입니다

| 물건 | 배출 |
|---|---|
| 부직포 장바구니, 사은품 가방 | 종량제봉투 |
| 옷 보관 커버, 정장 보관 가방 | 종량제봉투. 지퍼가 있어도 그대로 |
| 과일 부직포 포장재, 완충재 | 종량제봉투 |
| 일회용 앞치마, 일회용 행주 | 종량제봉투 |
| 부직포 마스크(KF94 등) | 종량제봉투. [마스크](/maseukeu/) 참고 |
| 물티슈, 화장솜 | 종량제봉투. 변기에 넣지 마세요 |
| 티백 | 찻잎째 통째로 종량제봉투. [티백](/tibaek/) 참고 |
| 육수팩 | 안의 멸치, 다시마는 음식물, 주머니는 종량제봉투 |
| 부직포 화분(그로우백) | 흙을 털고 종량제봉투 |

품목사전은 부직포 가방과 같은 답으로 육수팩, 티백, 과일 부직포 포장재, 일회용
앞치마, 정장 보관 가방, 신발 보관 커버를 묶어 둡니다.

## 의류수거함에 넣으면 안 됩니다

훈령 별표1 의류, 잡화 항목이 폐의류 전용수거함에 받는 것은 입던 옷과 잡화입니다.
부직포 가방을 넣으면 수거 업체가 골라내 버립니다. 새것이라도 마찬가지입니다.
사은품으로 받아 쌓인 부직포 가방은 재사용 말고는 갈 곳이 없습니다.

## 티백과 물티슈는 변기가 아닙니다

물티슈는 종이가 아니라 부직포입니다. 물에 안 풀려서 변기에 넣으면 배관과
하수처리장에서 걸립니다. 티백도 주머니가 부직포인 제품이 많습니다. 우린
찻잎은 음식물이 아니라서 티백은 **찻잎째 통째로 종량제봉투**입니다.

## 부피가 크면

부직포 옷커버나 이불 보관 가방은 접으면 얇아집니다. 봉투에 넣기 전에 접어서
끈으로 묶으세요. 대형폐기물 신고 대상이 되는 크기는 아닙니다.
