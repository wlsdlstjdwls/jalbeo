### 조사 전 예상이 뒤집힌 것

**파라솔.** 우산 별칭으로 접었다. 구조(살대, 천)가 같고 등재 수도 15 대 14다.
그런데 `build_fee_stats`를 돌리자 **우산 중앙값이 1,000원에서 2,000원으로
뛰고 최고가 4,000원에서 5,500원이 됐다.** 파라솔 값(2,000~7,000)이 우산
값(750~1,000)에 섞인 것이다. 판단 39번은 등재 수만 봤는데 **값의 배수도
봐야 한다.** 별칭을 철회하고 페이지로 냈다.

**식기건조기와 식기세척기.** 반대 방향이다. 답이 완전히 같아서(훈령 대형가전
예시에 둘 다, 무상방문수거) 한 페이지로 묶는 게 맞는데 수수료가 다르다
(건조기 0~2,000, 세척기 4,000~14,000). 별칭으로 받되 `build_fee_stats`의
EXTRA_ALIAS에서 `식기세척기: None`으로 막아 건조기 통계만 화면에 낸다.
본문이 세척기 값을 따로 적는다. 팩스도 같은 방식으로 전화기에서 막았다.

**책꽂이.** 별칭으로 넣자 책장 통계가 38곳 5,250원에서 44곳 4,000원으로
바뀌었다. `check_fee_claims`가 잡았고 본문을 고쳤다. 이건 같은 물건의 값이
합쳐진 것이라 그대로 두는 게 맞다.

### 페이지마다 나온 뼈대

- **타이어** -- 훈령이 "정비업소, 타이어판매소 등 역회수 경로"를 정해 뒀다.
  지자체 표는 인치, 지름 cm, 톤수, 폭 mm로 자가 제각각이다
- **전화기** -- 양평군, 광진구, 오산시가 품목표에 0원으로 올려 두었다.
  믹서기 때와 같은 자리다. 무선전화기 수화기의 전지가 갈림길
- **환풍기** -- 이름이 훈령에도 소형가전 목록에도 없어 정의로 답했다.
  E-순환거버넌스 수거 불가에 "인테리어 제품"이 있어 붙박이는 안 뗀다
- **핫팩** -- 품목사전이 일회용 손난로(일반)와 전기 손난로(재활용)를 따로 둔다.
  한국일보가 철가루에 활성탄, 소금, 질석이 섞인 이유를 적어 둬 인용했다
- **즉석밥 용기** -- 품목사전은 "플라스틱 수거함", 한국일보는 "선별장에선 쓰레기로
  버리거나 태워야 하는 경우가 많다". 판단 23번(출처가 갈리면 둘 다)대로 썼다
- **휠체어** -- 국립재활원 아래 16개 보조기기센터, 성남시 복지용구 공유센터가
  받는다. 전동은 납축전지를 훈령 경로(정비업소, 지자체 수거장소)로
- **헤어드라이어** -- 훈령 해당품목. 코드를 잘라 고철로 내는 통설을 반박했다
- **파라솔** -- 우산과 같은 분해 순서, 다른 값. 신고 화면에서 우산으로 잡지 말라고 썼다

## 2. 분리의정석 품목사전 씨앗 (실측 12차 준비)

`scripts/crawl_bunri_dictionary.py`가 품목사전 770개를 긁었다
(`data/raw/bunri-dictionary.json`, 이름과 분류). 상세 안내문은
`dictionaryView.do?niIdx=<id>`로 따로 열어야 한다.

`scripts/extract_bunri_seeds.py`가 발행분 어휘(이름 + 별칭 + 판정된 외부
후보)와 대조했다. 접기는 `extract_external_seeds`와 같은 규칙(표기 혼동
집합만, 판단 36)이다.

| | 수 |
|---|---|
| 품목사전 전체 | 770 |
| 접힘(이미 아는 말) | 192 |
| 신규 | 533 |
| 그중 재활용, 일반, 유해 분류 | 471 |
| 대형폐기물 전용 | 28 |
| 음식물류 | 28 |

접힌 예: 화분(플라스틱) -> 화분, 포크(복합 재질) -> 수저 별칭, 실크 벽지 -> 벽지
별칭, 닭뼈 -> 치킨뼈 별칭. 오접은 확인한 범위에서 없었다.

### 씨앗 출처 평가

수수료표(판단 37)와 성질이 반대다. 533개 중 471개가 재활용, 일반, 유해의
경계에 있고, 품목사전 자체가 "이건 재활용 / 이건 일반"을 가르는 목록이다.
14차(`docs/35`)의 여섯이 전부 여기 있었고 12차 후보의 뼈대(리모컨, 걸레,
지퍼백, 뚝배기, 짐볼, 교복, 라이터, 락스, 주사기)도 훈령에 없는 것들이다.
**품목마다 답이 갈리는 영역**이다. 다만 자동완성 빈도처럼 수요 순위는 아니다
(판단 16) - 그건 실측이 한다.

판단 39번(그릇 5곳 대 항아리 35곳)은 등재 수가 자릿수로 다르면 다른

적는다.
