## 시작점 — 실측 수요 풀은 진짜 소진돼 있었다

`gate1-volumes.csv`에서 검색량이 붙은 품목은 92개다. 그중 91개가 이미 발행돼
있었고 남은 것은 `다이소`(10) 하나뿐인데, 이건 매장명이라 품목이 아니다
(docs/11 판단 유지).

**그래서 확장 재료는 미측정 시드에서 찾았다.** `items.csv` 325개 중
가운데 104개만 숫자가 나왔고, 나머지 221개는 **0이 아니라 '모름'**이었다
(docs/09가 남긴 지적 그대로). 발행분과 겹치는 것을 빼면 **220개**가 남는다.

자동완성 크롤 빈도(`freq`)는 있다. 검색량만큼 정밀하지 않지만
"사람이 실제로 그렇게 친다"는 증거는 된다.

## 220개를 어떻게 갈랐나

기준은 하나다. **배출 경로가 실제로 갈리느냐.**

- **갈리면 신규 페이지** — LED 전구는 형광등 수거함, 조개껍질은 일반쓰레기,
  보조배터리는 전지 수거함. 기존 품목으로 답할 수 없다
- **안 갈리면 별칭** — 탄 냄비, 코팅냄비, 양은냄비는 전부 냄비다.
  차렵이불, 극세사 이불은 전부 이불이다

결과: **신규 59개, 기존 품목에 붙인 별칭 167개**(43개 품목에 배분).
신규 품목이 자기 별칭 118개를 더 들고 오므로 사이트 전체 별칭은 22개 → **306개**가 됐다.

**별칭이 신규의 세 배다.** 같은 답을 하는 페이지를 늘리면
scaled content abuse에 걸린다(docs/02 리스크 1). 페이지를 늘리는 대신
검색이 그 부담을 지도록 했다.

## 중복 페이지 2쌍을 접었다

발견하고 정리한 것이다.

| 접은 페이지 | 남긴 페이지 | 처리 |
|---|---|---|
| `syopa`(쇼파) | `sopa`(소파) | 본문 병합 + 별칭 + 301 리다이렉트 |
| `jangnong`(장농) | `jangrong`(장롱) | 본문 병합 + 별칭 + 301 리다이렉트 |

둘 다 **표기만 다른 같은 물건**이었는데 각각 페이지를 갖고 있었다.
내용이 완전히 같지는 않았으므로(쇼파 쪽은 인승별 수수료, 장농 쪽은 요금표
표기 문제를 다뤘다) 버리지 않고 **canonical 페이지로 흡수**했다.

리다이렉트는 `site/vercel.json`에 넣었다.

## 검색을 강화했다

중복을 접으면 그만큼 검색이 일을 더 해야 한다. `site/src/lib/search.ts`를
새로 두고 품목마다 검색 키를 만든다.

- **별칭** — '쇼파'로 쳐도 소파가 나온다
- **공백 무시** — '보조 배터리'로 쳐도 보조배터리가 나온다
- **초성** — 'ㅅㅍ'로 쳐도 소파가 나온다
- **로마자** — 'sopa'로 쳐도 나온다. slug가 곧 로마자 표기다
- **판정, 분류** — '전용수거함'으로 쳐도 걸린다

## 본문은 품목마다 따로 썼다

59개 전부 직접 조사해서 썼다. 템플릿에 데이터만 갈아끼우지 않았다
(`site/src/content.config.ts`의 경고 그대로).

근거로 가장 많이 쓴 것은 **훈령 별표1**이다. 이번에 새로 확인해 쓴 조항들:

- **조명제품** 항목 제목이 `형광등, 발광다이오드(LED) 조명`이다.
  **LED는 이제 형광등 수거함 대상**이고, 깨진 경우만 종량제봉투다.
  "LED는 수은이 없으니 일반쓰레기"라는 오래된 안내가 지금 기준으로는 틀렸다
- 합성수지 재활용 **제외 목록에 이름이 박힌 품목**들 —
  `옷걸이, 칫솔, 파일철, 낚싯대, 유모차, 보행기, CD, DVD, 여행용트렁크`
- 기타종이류 **제외 목록** — `택배전표, 영수증 감열지, 사진용지, 종이호일, 색지`
- 소형 전기전자제품 **예시 목록에 가습기, 전기밥솥**이 이름으로 있다
- 대형 전기전자제품 예시에 **건조기**가 들어갔다
- 금속캔 비고 — **`알루미늄 호일은 종량제봉투`**
- 합성수지 비고 — **`물로 헹굴 수 없는 구조의 용기류(치약용기 등)는 내용물을 비운 후 배출`**

`생활계 유해폐기물의 종류` 고시(제2025-165호)도 새로 붙였다.
국가가 정한 종류는 **폐페인트, 폐광택제, 폐접착제** 셋뿐이고 나머지는
조례로 넘긴다. 폐의약품, 매니큐어, 염색약이 지자체마다 다른 이유가 여기 있다.

## 수수료 데이터가 저절로 붙었다

`build_fee_stats.py`는 items.json의 이름과 별칭으로 수수료 CSV를 매칭한다.
품목과 별칭이 늘어난 만큼 **47개 → 75개**로 늘었다.

새로 붙은 것 중 표본이 큰 것: 세면대(40지역), 유모차(39지역), TV(32지역),
보냉가방(30지역), 재봉틀(28지역), 가습기(26지역), 건조기(25지역).

**곁다리로 버그를 하나 고쳤다.** `EXTRA_ALIAS`에 `"옷장": "jangrong"`이
있어서 옷장(`otjang`)의 수수료를 장롱이 가져가고 있었다. 옷장은 원래
자기 페이지가 있는 품목이다. 그 줄을 뺐다.
