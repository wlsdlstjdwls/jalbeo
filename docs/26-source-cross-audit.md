# 출처 교차 대조 — 지자체와 E-순환거버넌스

> 2026-09-07. `docs/25`가 남긴 "아직 안 본 감사 축" 1번이다. 훈령은 다 봤으니
> 지자체와 E-순환거버넌스를 인용하는 페이지끼리 답이 갈리는지 봤다.
> `docs/25`에서 제일 수확이 컸던 방법(같은 출처를 인용하는 페이지 교차 대조)을
> 훈령이 아닌 출처에 그대로 돌린 회차다.

## 결론 먼저

1. 같은 출처를 두 곳 이상이 인용하는 URL이 **31개**였다. 그중 E-순환거버넌스
   두 페이지를 29개 품목이 인용해 제일 크다
2. 페이지가 출처와 어긋난 것 **5건**, 출처가 말하는 갈림을 안 적은 것 **1건**
3. 그중 하나(전자피아노)는 **답 자체가 반대**였다. 수거 불가 품목인데
   무상수거로 무료라고 적혀 있었다
4. 이어서 수수료 축을 다시 훑어 **5건**을 더 고쳤고, 검사기를 넓혔다

## 1. 어떻게 골랐나

품목 md의 프런트매터 `sources[].url`을 전부 뽑아 URL로 묶었다. 두 곳 이상이
인용하는 URL만 남기면 31개다.

| 출처 | 인용 페이지 |
|---|---|
| E-순환거버넌스 이용안내 | 24개 |
| 영등포구 대형폐기물 품목표 | 15개 |
| 서울시 헷갈리는 분리배출 기준 | 10개 |
| E-순환거버넌스 단일수거 품목 | 8개 |
| 관악구 대형폐기물 배출방법 | 6개 |
| 관악구 재활용 의류 배출 | 5개 |

묶은 다음 그 출처를 인용한 문장만 모아 나란히 읽었다. 답이 갈리는 곳에서만
원문을 다시 받아 대조했다.

## 2. E-순환거버넌스가 목록으로 답한다

이 출처는 크기와 무게로 등급을 나누는 표를 크게 실어 두어서, 페이지들이 그
표를 근거로 삼는 경향이 있었다. **그런데 그 표는 품목 목록에 이름이 없는
가전에만 쓰는 것이다.** 이름이 실린 품목은 표를 거치지 않는다.

- **단일수거 가능 품목** — 냉장고, 세탁기, 에어컨, TV, 태양광패널, 그리고
  일반 전자제품(전기오븐, 자동판매기, 러닝머신, 식기건조기, 식기세척기,
  복사기, 전기정수기, 냉온수기, 공기청정기, 전자레인지, 제습기). 1대부터
- **다량 배출 품목** — 가습기, 청소기, 선풍기, 전기밥솥, 노트북, 모니터,
  프린터, 헤어드라이어 등 38개. 5개 이상
- **수거 불가 품목** — 원형훼손, 빌트인, 안마의자, 폐가구, 러닝머신을 제외한
  운동기구, **악기류(피아노, 전자 피아노 등)**, 의료기기, 전기를 쓰지 않는
  제품류(가스레인지 등)

제습기와 전자레인지 페이지는 이 구조를 이미 정확히 쓰고 있었다("이 표는 품목
목록에 이름이 없는 가전을 가를 때 씁니다"). 그 문장이 기준이 되어 나머지가
걸렸다.

## 3. 고친 것

**전자피아노 — 답이 반대였다.** "무상방문수거로 무료 처리됩니다. 1대만 있어도
무료 수거 대상"이라고 적혀 있었다. 같은 안내문의 수거 불가 품목이
"악기류(피아노, 전자 피아노 등)"이다. 세 변의 합 150cm를 넘는다는 계산은 맞지만
품목 자체가 빠져 있어서 그 계산에 들어가지 않는다. 대형폐기물로 통째 고쳤다.

**선풍기 — 사이트 안에서 이미 어긋나 있었다.** 선풍기 페이지는 "스탠드형은
1대만 있어도 무료 수거 대상"이라 했는데, 청소기 페이지는 다량배출 목록을
나열하며 "가습기, 전기밥솥, 전기주전자, 헤어드라이어, **선풍기**와 같은 자리"라고
적고 있었다. 원문을 보면 선풍기는 다량 배출 품목이다. 크기와 무관하게 5개
이상이다. 옵션 블록까지 다시 짰다.

**프린터 — 예시가 틀렸다.** "프린터, 가습기, 공기청정기 같은 소형
전기전자제품은 5개 이상"이라 적었는데 공기청정기는 단일수거 품목이다.
공기청정기 페이지는 반대로 맞게 적고 있었다.

**가스레인지 — 출처가 못박은 것을 흐려 놨다.** "무상수거 대상인지는 지역과
접수처에 따라 답이 갈리므로"라고 썼는데, 출처는 수거 불가 품목에 "기타 전기를
사용하지 않는 제품류(가스레인지 등)"로 괄호까지 넣어 이름을 적어 두었다.

**안마의자 — 출처가 자기모순이다.** 수거기준표 아래에는 "안마의자는 집밖으로
배출되어야 수거 가능"이라는 예외 문구가 있고, 같은 문서 수거 불가 품목 표에는
"전기안마기 중 안마의자"가 있다. 페이지는 앞의 것만 보고 "처리할 수 있습니다"로
단정했다. 둘 다 적고 예약 전 확인을 권하는 쪽으로 바꿨다.

**이불 — 자치구가 서울시와 다르다.** 이불 페이지는 서울시를 근거로 "의류수거함에
넣으면 안 되는 대표 품목"이라 했는데, 가방과 신발 페이지가 인용하는 관악구
안내는 수거대상 품목에 "담요, **누비이불**, 커튼, 카펫, 베개커버, 이불커버"를
올려 두었다. 수거불가는 "솜이불, 베개, 방석"이다. 갈리는 것은 이불이냐가 아니라
**충전재가 들어찼느냐**다. 예외 절을 넣었다.

## 4. 안 걸린 것

전부 열거하지 않지만, 확인하고 그대로 둔 것이 더 많다.

- 관악구 의류수거함 목록을 인용한 5개 페이지는 인용문이 글자까지 일치했다
- 강동구 불연성 특수규격마대를 인용한 4개 페이지는 서로 어긋나지 않았다
- 강동구, 세종시, 강서구 음식물 안내를 인용한 페이지들은 오히려 **세 곳이
  다르다는 것 자체를 본문에서 비교**하고 있었다. 김치 페이지가 대표적이다
- 성동구 수수료표를 인용한 4개 페이지는 규격 구분(높이 50cm, 가로 50cm)을
  일관되게 인용했다

## 5. 수수료 축에서 5건 더

`check_fee_claims.py`가 중앙값과 지역 수만 보고 있었다. **범위를 안 보고
있었다.** 최소, 최대, "범위는 A~B원", "요금을 공개한 N곳" 패턴을 붙였더니
검사 건수가 56건에서 111건으로 늘고 5건이 걸렸다.

| 품목 | 본문 | fees.json |
|---|---|---|
| 변기 | 35곳, 낮은 곳 2,000원 | 36곳, 3,000원 |
| 장롱 | 쪽당 높은 곳 13,500원 | 20,000원 |
| 옷장 | 높은 곳 12,500원 | 5,000원 |
| 옷걸이 | 32곳 | 40곳 |
| 세탁기 | 34곳 | 39곳 |

옷걸이와 세탁기는 `docs/25`가 최다 유형으로 적어 둔 **행 수를 시군구 수로 적기**의
재발이다. 그때 잡은 것은 "N개 시군구 품목표" 어법뿐이었고, "요금을 공개한 N곳"
어법은 검사에 안 걸렸다.

## 여기서 얻은 것

1. **출처가 목록으로 답하면 계산식보다 목록이 먼저다.** E-순환거버넌스의
   등급표는 이름 없는 품목에만 쓴다. 이걸 모르면 큰 물건일수록 틀린다
2. **출처가 자기모순인 경우가 있다.** 안마의자는 같은 PDF 안에서 답이 둘이다.
   이때 한쪽만 적으면 페이지가 틀린 게 된다. 둘 다 적는다
3. **서울시와 자치구가 다르다.** 이불처럼 상위 지자체 기준으로 단정하면
   자치구 안내와 어긋난다. 우리 사이트가 이미 두 답을 다 인용하고 있었다
4. **검사기는 잡는 어법만 잡는다.** 같은 종류의 오류가 다른 문장 모양으로
   재발했다. 오류를 고칠 때 그 문장 모양을 검사기에 같이 넣는다
