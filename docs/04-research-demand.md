# 검색 수요 조사

> 조사일 2026-09-03 / 방법: 네이버 자동완성 API (`ac.search.naver.com`)
> 원본 응답: `../data/raw/naver-autocomplete.md`

**주의**: 자동완성은 검색량 수치가 아니라 **수요의 형태**를 보여주는 신호다.
정확한 볼륨은 네이버 검색광고 키워드도구(로그인 필요)에서 별도 실측해야 한다.

## 결론 — 원안의 B층 가설이 깨졌다

### 발견 1. 품목 + 지역 조합은 사실상 검색되지 않는다

```
"침대 버리는법 서울"  → 자동완성 0건
"TV 버리는법"        → tv 버리는법 / tv 버리는법 아파트          (지역 없음)
"매트리스 버리는법"   → 스티커 / 무료 / 어플 / 가격 / 아파트 / 온라인
"쇼파 버리는"        → 비용 / 방법 / 어플 / 가격 / 업체 / 금액 / 스티커
"냉장고 버리는"      → 비용 / 방법 / 가격 / 곳
```

품목 뒤에 붙는 수식어는 **지역이 아니라 가격, 스티커, 어플, 무료, 아파트**다.

원안의 타깃 예시였던 "매트리스 버리는법 용산구" 형태의 검색어는 자동완성에 나타나지 않는다.

### 발견 2. 지역 검색은 다른 형태로 존재하며, 그건 구청 영역이다

```
"용산구 대형폐기물" → 신고 / 신청 / 배출 / 수거 / 스티커 / 처리 / 신고방법
"서울 대형폐기물"   → 신고 / 스티커 / 처리 / 신고앱 / 무료수거 / 스티커가격
"대형폐기물"        → 신고 / 인터넷신고 / 스티커 / 수거 / 가격
                     + 관악구, 부천시, 제주 대형폐기물
```

"용산구 **매트리스**"가 아니라 "용산구 대형폐기물 **신고**".
신고 검색은 구청 사이트로 직행한다. 여기엔 끼어들 자리가 없다.

**→ 품목 100 × 지자체 30 = 3,000페이지는 "검색어가 없는 페이지" 3,000개가 될 가능성이 높다.**

예외: 소형품목은 지역이 붙는다. "건전지 버리는법 송파구 / 울산" —
수거함 위치가 지자체마다 다르기 때문. 이 유형만 지역 축이 유효하다.

### 발견 3. A층(품목)은 수요가 확인된다

```
"버리는법"      → 캐리어 / 그릇 / 책 / 쌀 / 토퍼 / 선풍기 / 약 / 수건 / 유리 / 우산
"분리수거 방법"  → 후라이팬 / 책 / 이불 / 칼 / 컵라면 / CD / 전선 / 우산 / 빨래건조대
"치킨뼈"        → 분리수거 / 음식물 / 일반 / 버리는 방법
"아이스팩 버리는법" → 젤 / 곡물 / PCM 아이스팩
"건전지 버리는법"   → 일반 / 주민센터 / 동사무소
```

자동완성이 전부 품목별로 갈라진다. 원안 A층 예시(프라이팬, 옷걸이, 아이스팩)와 정확히 겹친다.
**여기가 실제 광맥이다.**

또한 "젤/곡물/PCM 아이스팩"처럼 **하위 변종**까지 갈라진다 → 품목 페이지를 세분화할 여지가 있다.

### 발견 4. 검색 의도에 거래 의도가 섞여 있다

`비용 / 가격 / 금액 / 업체 / 무료수거 / 어플 / 스티커 가격`이 반복 등장.

사용자는 정보만 원하는 게 아니라 **얼마인지, 누가 가져가는지**를 찾고 있다.
애드센스보다 수거업체 제휴, 리드 생성이 수익성이 높을 가능성이 있다.
