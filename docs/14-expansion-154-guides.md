## 1. 실측 2차 — 발행 품목 59개의 검색량

`docs/13`이 남긴 숙제였다. 5차 확장으로 발행한 59개는 monthly_volume이 null이었다.
`{품목}버리는법`과 `{품목}분리수거` 두 어미를 씨앗으로 넣어 실측했다.

합계 41,890. 상위는 보조배터리 10,790, 멀티탭 2,650, 충전기 2,590, CD 2,270.

### 어미가 품목마다 뒤집힌다

직전 커밋에서 B안(분리수거)을 뺐는데, 실측은 그 판단이 틀렸다고 말한다.

```
품목        버리는법   분리수거
빨대            45    1,690    38배
조개껍질         25    1,570    63배
뽁뽁이         280    1,770
칫솔           130    1,140
보조배터리    9,660    1,130    반대 방향
충전기        2,240      350
```

페이지는 이미 타이틀에 두 어미를 다 태우고 있어서(`[...slug].astro`) 구조 변경은
필요 없었다. 다만 **한 어미만 재고 품목을 버리면 안 된다**는 것이 확인됐다.
이후 실측은 두 어미를 기본으로 한다.

### 1차 값과 2차 값은 스케일이 다르다

1차(`gate1-volumes.csv`)는 씨앗이 아니라 연관어 덤프였다. 품목마다 우연히 걸린
어미가 달라서 합계 기준이 제각각이다.

```
이불   26,905 = 버리는방법 19,580 + 버리는법 3,140 + 버리기 2,380 + ...
선풍기 12,120 = 버리는법 12,120 (어미 1개만 걸림)
```

1차 92개를 2차 자로 다시 재면 232,525 -> 166,895(71%)다. 품목별 편차가 커서
(이불 11%, 화분 8%, 선풍기 100%) 한 컬럼에 놓고 정렬하면 순위가 뒤집힌다.
1차 92개 중 두 어미를 다 가진 품목은 3개뿐이다.

**정리하려면 남은 89품목에 두 어미를 실측해야 한다. 178키워드, 36배치.**
그때까지 monthly_volume은 절대 크기가 아니라 대략의 등급으로만 읽는다.

### 가이드 페이지 3개 신설

품목 페이지가 아니라 **절차 페이지**다. `/guides/` 아래로 URL 공간을 나눴다.
품목 라우트가 루트를 다 먹기 때문이고, 답의 성격도 다르다. 품목은 "어디에
버리나", 가이드는 "어떻게 신청하나"다.

| URL | 노리는 축 |
|---|---|
| `/guides/pyegajeon-musang-sugeo/` | 145,940 |
| `/guides/daehyeong-pyegimul-singo/` | 36,830 |
| `/guides/pyegagu-mulyo-sugeo/` | 16,035 |

타이틀에는 `무료수거`와 `무상수거`를 함께 태웠다. 공식 명칭은 무상방문수거지만
검색은 무료수거가 3배다.

폐가구 가이드의 답은 "안 된다"이다. 무상방문수거의 재원이 생산자책임재활용이라
가구는 대상 자체가 아니다. 검색자의 기대와 실제 답이 어긋나는 자리라 경쟁이 얕다.
