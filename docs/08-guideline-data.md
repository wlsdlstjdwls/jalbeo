### 별표1 「분리수거대상 재활용가능자원의 품목 및 분리배출요령」

8쪽 표. 표 괘선에서 행 경계를, x좌표에서 열을 잡아 셀 단위로 파싱했다.

- 세부품목 레코드 **19개**, 품목 판정 **73건** (O 32 / X 41)
- `해당품목` → 그 분류로 배출 가능(O), `비해당품목` → 불가(X)

O·X가 그대로 쓸 수 있게 나온 예:

```
X  깨진유리제품, 내열유리제품, 크리스탈유리제품, 판유리, 조명기구용유리류  (유리병 아님)
X  옷걸이, 칫솔, 파일철, 낚싯대, 유모차, CD·DVD, 여행용트렁크          (플라스틱 용기 아님)
X  이불, 베개, 방석, 인형, 골프가방, 가죽부츠                        (의류수거함 아님)
X  택배전표, 영수증 감열지, 사진용지, 종이호일, 색지                    (종이류 아님)
O  TV, 냉장고, 세탁기, 건조기, 에어컨, 태양광패널  (대형 전기·전자제품)
O  가습기, 청소기, 전기밥솥, 전기주전자, 헤어드라이어  (소형 전기·전자제품)
```

**파싱 범위는 섹션 1뿐이다.** 섹션 2(통합배출)는 4열 표, 섹션 3(기타 재활용가능자원 —
고철·농약용기·타이어·납축전지·식용유·윤활유·원단)은 열 좌표가 달라 자동 파싱이 깨진다.
원본 PDF·HWP로 보관했고, 필요 시 수동 정리한다.

## 핵심 발견 — 음식물 판정에는 국가 기준이 없다

`음식물류 폐기물` 관련 행정규칙 4건을 전수 확인했다. 전부 억제계획·매립지역 지정·
수수료 산정 같은 행정 절차 규정이고, **품목별 음식물/일반 판정을 정한 국가 고시는 없다.**

즉 수박껍질·계란껍질·양파껍질·치킨뼈의 O·X는 **지자체 조례와 소각·처리시설 사정에 따라 갈린다.**

이건 `07-keyword-seed.md`에서 관측한 현상과 정확히 맞물린다.
지역 수식어가 붙는 품목 16개 중 **수박껍질·바나나껍질이 1·2위**였다.
사람들이 "수박껍질 음식물 대구 / 제주 / 인천"을 치는 이유가 이것 —
**실제로 지역마다 답이 다르기 때문이다.**

시사점 두 가지:

1. **음식물 판정 품목이 이 사이트의 진짜 차별화 지점이다.**
   전국 공통 정보만 제공하는 경쟁 사이트(블리스고)가 구조적으로 답할 수 없는 영역이고,
   구청 사이트는 신고·수수료 위주라 품목별 판정을 잘 다루지 않는다.
2. 다만 데이터 확보 비용이 크다. 지자체 조례를 품목 단위로 파싱해야 한다.
   `03-research-datasource.md`에서 조례 파싱을 "백업 수단"으로 미뤄뒀는데,
   음식물 축에서는 **1차 수단**이 된다.

## 아직 없는 것

- **「쓰레기 수수료 종량제 시행지침」** — 별표1 비고가 대형폐기물 관리를 이 지침에 위임한다.
  법령정보센터 행정규칙 검색에 안 잡힘. 환경부 발간자료 쪽에서 별도 확보 필요.
- **음식물류 폐기물 품목별 판정** — 국가 기준 부재(위 참조). 지자체 조례에서 뽑아야 한다.
- **「내 손안의 분리배출」 품목 DB** — 한국환경공단 앱. 웹 엔드포인트를 못 찾음.
  자원순환실천플랫폼(recycling-info.or.kr)은 레거시 포털로 품목 DB를 노출하지 않는다.
