# 게이트 1 결과 — 통과

> 실측일 2026-09-03 / 출처: 네이버 검색광고 키워드도구
> 원본: `../data/keywords/gate1/` (13개 파일, git 제외) · 집계: `../data/keywords/gate1-volumes.csv`
> 기준(`CLAUDE.md`): 상위 100개 키워드 월간 검색량 합계 **10만 미만이면 중단**

## 판정

| 집계 방식 | 상위 100개 합계 | |
|---|---:|---|
| 느슨하게 (전체 2,502개) | 6,143,770 | 쓰지 않음 |
| **품목축만 (265개)** | **219,310** | **← 판정 기준** |

**기준선 10만의 2.2배. 통과.**

느슨한 집계를 버린 이유: 연관키워드에 `금시세`(537만)·`쌈밥`(34,830)이 섞여 들어온다.
키워드도구는 씨앗 5개당 연관어를 최대 수백 개 뱉는데, 그 대부분이 우리가 답할 수 없는
검색어다. 합계에 넣으면 게이트가 게이트 구실을 못 한다.

품목축 = 우리 품목 사전에 있는 단어 + 배출 의도 어미(`버리`·`분리수거`·`폐기`·`음식물`…)를
둘 다 가진 키워드만.

## 수요 분포 — 상위 집중이 심하다

품목축 265개 키워드, 합계 232,525. **92개 품목**에 수요가 붙었다.

```
이불     26,905      화분      8,635      건전지    3,760
선풍기   12,120      그릇      7,780      수건     3,700
후라이팬 12,100      인형      7,110      식용유    3,430
유리     11,395      신발      6,595      쇼파     3,300

캐리어    8,730      냄비      5,910      바나나껍질  2,710
```

꼬리는 얇다. 하위권은 페트병 70 · 양파껍질 65 · 프린터 50 · 낙엽 10 · 갈비뼈 10.

**시사점: 원안의 "품목 페이지 500~800개"는 과대하다.**
수요가 확인된 92개 + 미측정분을 감안해도 **실질 100~150개**가 현실적인 규모다.
페이지를 늘리는 게 아니라 상위 20~30개를 깊게 만드는 쪽이 맞다.
`02-review.md` 리스크 1번(scaled content abuse) 관점에서도 이쪽이 안전하다.

### 측정 안 된 품목이 233개다

`items.csv` 325개 중 92개만 숫자가 나왔다. 나머지는 **0이 아니라 "모름"이다.**
13개 배치의 연관키워드에 우연히 걸린 것만 측정됐다. 필요하면 남은 품목을 직접 조회해야 한다.
다만 게이트 판정에는 영향이 없다 — 이미 2.2배로 통과했고, 추가 측정은 숫자를 올리기만 한다.

## 앞선 판단 중 흔들린 것 2개

### 1. 음식물 축 — 수요가 생각보다 작다

`08-guideline-data.md`에서 "음식물 판정이 진짜 차별화 지점"이라고 봤다.
근거는 국가 기준 부재 + 지역별로 답이 갈린다는 점이었다. 그 분석 자체는 유효하다.

그런데 **실측 수요는 8,970으로 전체의 3.9%뿐이다.**

```
수박껍질 3,850 / 바나나껍질 2,710 / 김치 1,040 / 치킨뼈 960
계란껍질 130 / 양파껍질 65 / 과일껍질 35
```

수박껍질·바나나껍질 두 개가 73%다. 나머지는 사실상 없다.

→ **차별화 지점인 건 맞지만 성장축은 못 된다.** 상위 2개만 제대로 만들고 나머지는
품목 페이지 안의 한 줄로 처리하는 게 비용 대비 맞다. 조례 파싱 투자는 보류.

### 2. 거래 의도 축 — 자동완성이 과대 신호였다

`07-keyword-seed.md`에서 비용·스티커·업체·무료 수식어가 60건 관측돼
`02-review.md`의 "제휴 수익" 판단을 뒷받침한다고 봤다.

실측하니 **품목축 안에서 거래의도 키워드는 21개 / 3,315뿐**이다.

자동완성은 "그런 형태의 질문이 있다"를 보여주지만 크기는 안 보여준다. 이번이 그 차이다.
제휴 수익 가설은 품목 페이지 축에서는 근거가 약하다. 다만 아래 인접 시장은 다르다.

## 새로 보이는 것 — 인접 시장이 품목 페이지보다 크다

품목축 밖이라 게이트 합계에서 뺐지만, 실제 수요는 여기가 더 크다.

```
폐가전무료수거   51,830        대형폐기물신고   32,800
폐기물스티커     41,560        대형폐기물      24,790
폐가전무상수거   17,830        소형가전무료수거  17,330
```

`04-research-demand.md`가 "대형폐기물 신고 검색은 구청 영역이라 끼어들 자리가 없다"고
판단해 B층을 폐기했다. 그 판단은 유지한다 — `대형폐기물신고`는 구청 사이트로 직행한다.

다만 **`폐가전무료수거`(51,830)·`폐가전무상수거`(17,830)는 성격이 다르다.**
정부 무상수거 서비스(폐가전 무상방문수거)를 찾는 검색이고, 구청 페이지가 잘 답하지 않는다.
품목 페이지와 별개 축으로 검토할 가치가 있다. 게이트 2 이후 판단.
