## 유입 공백

`scripts/inflow_report.py`를 세션 시작 때 돌리니 품목/가이드 검색 착지가
9/29 이후 0건이었다. 9/19~9/29는 11일 중 10일 찍혔고 9/30~10/12는 13일째 0이다.

계측이 깨졌는지부터 봤다.

| 확인 | 결과 |
|---|---|
| 리퍼러 수집 | 10/11 m.search.naver.com, 10/12 chatgpt.com, l.threads.com 정상 기록 |
| 검색어 로그 | 10/9, 10/11, 10/12 적재 |
| 9/27~10/1 커밋 | 없음. 공백이 배포와 안 겹친다 |
| 상위 착지 페이지(가스레인지, CD, 안마의자, 염색약, 유리병) | 구글봇 UA로 200, meta robots 없음, canonical 자기 자신 |
| robots.txt, `/sitemap-index.xml`, `/deploy.json` | 정상, 배포본이 최신 커밋 |

계측과 사이트 둘 다 멀쩡하다. **구글 순위가 실제로 빠진 것이고 고칠 파일이 없다**
(판단 30, 93). 새 도메인 초기 출렁임으로 보고 기다린다. 애드센스 재신청
("품목 유입이 매일 찍힐 때")은 그만큼 밀린다.

## 예약 크롤러 몰림

원본 행을 펴다가 10/10 12:44~12:46 2분 동안 UUID 37개가 리퍼러 없이 들어온 것을
봤다. 훑은 페이지가 과거 구글 착지 페이지(가스레인지, 안마의자, 뽁뽁이, 유리병,
정수기)뿐이다. 단발(그 UUID의 평생 조회 1건) + 무리퍼러 행을 시간대로 묶으니:

- 9/22부터 **사흘 간격 정오(KST)마다 32~36건**: 9/22, 9/25, 9/28, 10/1, 10/4, 10/7, 10/10
- 9/19 05~08시, 9/27 12~14시에 시간당 30건 안팎의 느린 크롤

우리 워크플로 cron은 최신성 체크(월 09:00)뿐이라 외부다. UA에 봇 표식이 없고
2초 체류도 넘으므로 `docs/31`의 두 겹을 다 통과한다.

**기준.** 단발 + 무리퍼러 행이 앞뒤 10분 안에 5개 이상이면 몰림이다.
5분 8개로 하면 9/19(116 남음), 9/27(79 남음)을 놓친다.

| 기준 | 9/19 남은 방문자 | 9/27 남은 방문자 |
|---|---|---|
| 5분, 8개 | 116 | 79 |
| 10분, 5개 | 8 | 5 |

**어디서 끊나.** 들어올 때는 몰림이 안 보인다(뒤에 와야 안다). 판단 32대로
행은 두고 읽는 쪽에서 끊는다. `db/migrations/0011_burst_filter.sql`이
`page_views_human` 뷰(security_invoker, anon/authenticated 권한 없음)를 만들고
0008의 관리자 읽기 함수 넷을 그 뷰로 돌렸다.

- 9/8 이후 조회 726 -> 231, 방문자 683 -> 188
- 검색엔진 착지 37 -> 37 (리퍼러가 있는 행은 안 건드린다)

`inflow_report.py`는 리퍼러 있는 행만 세므로 바꾸지 않았다.
