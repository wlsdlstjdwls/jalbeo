## 데이터 정리에서 나온 것

- **`가스레인지`(430)와 `가스렌지`(205)는 같은 품목이었다.** 페이지 두 장으로
  만들면 그대로 중복 콘텐츠가 된다. 합쳐서 635, 표기 변종은 alias로 넣었다
- **`장농`은 `장롱`의 오기**다. 표제를 바로잡고 오기를 alias로 남겼다
- **`다이소`(10)는 품목이 아니라 매장명**이라 대상에서 제외했다

자동완성에서 뽑은 시드에는 이런 것이 섞인다. 페이지를 만들기 전에 걸러야 한다.

## 중복도 측정

scaled content abuse가 최대 리스크(`02-review.md` 리스크 1)이므로 배포 전에 쟀다.

| 지표 | 값 |
|---|---|
| 본문 길이 (공백 제외) | 평균 875자, 최소 714, 최대 1,135 |
| 페이지쌍 3-gram 자카드 유사도 | **평균 0.083** |
| 최대 유사 페이지쌍 | 0.300 (청소기 ~ 선풍기) |
| 3개 이상 페이지에 그대로 반복되는 문장 | 2개 |

가장 비슷한 쌍이 청소기~선풍기(0.300)인 이유는 둘 다 폐가전 무상수거 기준표를
싣기 때문이다. 같은 규정을 인용하는 것이라 불가피하다. 나머지 본문은 다르다.

반복되는 문장 2개는 무상수거 기준표의 중소형 행과 "지자체 대형폐기물 신고" 안내다.
사실 자체가 같아 표현을 바꿔도 의미가 없다.

## 집필 원칙

품목마다 **"이게 왜 헷갈리는가"**를 먼저 찾고 거기서 시작했다. 템플릿에 데이터를
갈아끼우는 방식은 쓰지 않았다.

실제로 나온 것들:

- **선풍기** — 스탠드형은 1대부터 무료, 탁상용은 5개 이상. 세 변 합 150cm/12kg에서 갈린다
- **전자레인지** — 크기는 대부분 150cm에 못 미쳐 **무게 12kg이 실제 판단선**이 된다
- **인형** — 훈령이 의류수거함과 완구류 **양쪽에서** 비해당으로 지정해 종량제로 간다
- **소화기** — 소방서는 받지 않는다. 지자체 199곳(87.3%)이 대형폐기물로 처리
- **자전거** — 스티커부터 사면 손해. 자치구 수거 → 재생자전거 기증 → 고물상 순
- **피아노** — 품목 목록에 피아노가 없는 지자체가 있어 신고 전 전화 확인이 필요
- **카시트** — 사고 이력이 있으면 겉이 멀쩡해도 중고로 넘기면 안 된다
- **골프채** — 스틸 샤프트는 고철, 카본은 종량제. 자석으로 구분된다
- **계란껍질** — 석회질이라 사료화가 안 돼 일반쓰레기. 국가 기준은 존재하지 않는다

모든 페이지에 출처 URL과 기준일자를 함께 넣었다 (`CLAUDE.md` 작업 규칙).
