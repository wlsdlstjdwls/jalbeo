- 가용성은 `05-naming-domain.md` 참조 (2026-09-03 기준, 재확인 필요)

### 2. 키워드 볼륨 실측 — **게이트 1**
- 네이버 검색광고 키워드도구 (로그인 필요) + 구글 키워드플래너
- 입력값: 작업 3번의 품목 시드 CSV
- **이 숫자가 프로젝트 진행 여부를 결정한다**
- 중단 기준: 상위 100개 키워드 월간 검색량 합계 **10만 미만이면 접는다**

## Claude가 할 수 있는 것

### 3. 품목 시드 리스트 생성
- 네이버 자동완성 재귀 크롤링
- 시드 패턴: `{ㄱ~ㅎ} 버리는법`, `{ㄱ~ㅎ} 분리수거 방법`, `{품목} 음식물`
- 산출물: 품목 300~500개 CSV → `data/keywords/items.csv`
- 이게 작업 2번의 입력값

### 4. 환경부 분리배출 가이드라인 확보
- 품목 페이지 O·X 판정의 근거 데이터
- 출처 URL과 기준일자를 함께 저장

### 5. 경기권 수수료 데이터 수집
- 공공데이터포털 78건 다운로드 → 통합 스키마로 정규화
- 지자체마다 컬럼명이 달라 매핑 테이블 필요
- 서울은 데이터가 없으므로 이 단계에서 제외 (`03-research-datasource.md` 참조)

## 게이트 1 통과 후

- DB 없음. 데이터는 JSON/CSV 빌드타임 주입

### 7. 파일럿 배포 — **게이트 2**
- 품목 페이지 **20개만** 배포

- 중단 기준: 색인 실패 시 확장 금지 (구글 scaled content abuse 리스크)

### 8. 확장
