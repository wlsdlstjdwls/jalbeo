# 8차 확장 161 -> 164, 실측 6차 별칭 재측정

2026-09-04. `docs/18`에서 두 번 연속 걸린 것(요가매트, 퍼즐매트)을 우연으로
두지 않고 **별칭을 계통적으로 다시 쟀다.** 40개를 재서 5개가 뒤집혔고, 그중
답이 갈리는 3개를 페이지로 올리고 1개를 개명했다.

## 1. 왜 별칭을 다시 재나

별칭을 붙이면 그 단어의 수요가 안 보인다. 우연히 걸린 사례가 셋이었다.

```
영양제 -> 약        92배   docs/14   개명
러그 <- 요가매트     2.2배  docs/18   분리
범퍼침대 <- 퍼즐매트  8.0배  docs/18   분리
```

셋 다 **다른 단어**였다는 공통점이 있다. `쇼파`(소파)처럼 본체 이름을 품은
표기변형은 정의상 수요가 안 갈린다. 그래서 대상을 이렇게 좁혔다.

1. 본체 이름을 품은 별칭 제외
2. 본체 검색량 4,000 이하만 (뒤집히려면 본체가 작아야 한다)

별칭 364개 중 40개가 남았다. 80키워드, 16묶음이다
(`data/keywords/gate1-batches-6.md`).

## 2. 실측 6차 결과

집계기는 `scripts/gate1_batch6_aggregate.py`, 결과는
`data/keywords/gate1-volumes-6.csv`다. 5차까지의 집계기는 기준선(300) 통과
여부를 봤는데, 6차는 대상이 이미 접힌 별칭이라 **본체 대비 배수**로 판정한다.

40개 전부 측정됐다. 미측정 0.

| 별칭 | 합계 | 본체 | 본체량 | 배수 | 판단 |
|---|---:|---|---:|---:|---|
| led등 | 880 | LED 전구 | 115 | 7.65x | 분리 |
| 은박지 | 1,395 | 호일 | 255 | 5.47x | 개명 |
| 모기장 | 505 | 방충망 | 105 | 4.81x | 분리 |
| 밥상 | 265 | 식탁 | 80 | 3.31x | 분리 |
| 전기매트 | 365 | 전기장판 | 140 | 2.61x | 유지 |

나머지 35개는 최고가 장류 1.69배다. 뒤집힘이 없다.

## 3. 판정 하나하나

**led등 -> 분리.** 같은 물건이 아니다. 램프(전구, 직관등)는 훈령이 형광등
수거함으로 보내고, 천장 등기구(방등, 거실등, 평판등)는 대형폐기물 품목표가
받는다. 답이 갈리므로 개명이 아니라 페이지를 나눈다. `LED 전구` 페이지에서
평판등 문단을 빼고 링크로 넘겼다.

**은박지 -> 개명.** 같은 물건이고 5.47배다. `호일`을 별칭으로 내리고
slug을 `hoil` -> `eunbakji`로 바꿨다. 옛 경로는 `astro.config.mjs` 리다이렉트로
흘려보낸다(영양제 -> 약과 같은 처리).

어미가 극단으로 쏠린 사례이기도 하다. `은박지분리수거` 1,380 대
`은박지버리는법` 15다. 재활용이 되느냐를 묻는 검색어인데 답은 안 된다는
쪽이라, 본문 첫 줄을 그 답으로 바꿨다.

**모기장 -> 분리.** 방충망은 알루미늄 새시가 절반이라 틀이 고철로 빠지고,
모기장은 틀이 없는 섬유 제품이라 폴대만 빼면 종량제봉투다. 어미도 반대로
쏠린다(`모기장버리는법` 460 대 `모기장분리수거` 45).

**밥상 -> 분리.** 지자체 품목표에서 식탁과 다른 칸에 있고 값이 절반쯤이다
(밥상 중앙값 2,500원 32지역, 식탁 5,000원 46지역). 교자상(60)도 식탁에서
떼어 밥상 별칭으로 옮겼다.

**전기매트 -> 유지.** 같은 물건이고 배수가 다섯 중 가장 낮다(2.61). 개명하면
지자체 품목표의 표준 이름인 `전기장판`을 제목에서 잃는다. 대신 본문에
전기매트를 같은 물건으로 명시했다. 다음 회차에 다시 잰다.

## 4. 수수료 매핑을 하나 고쳤다

새 페이지를 붙이다 발견했다. 대형폐기물 품목표의 `형광등류`, `형광등(갓포함)`,
`전등 기구류`는 **램프가 아니라 등기구**다. 램프는 수거함으로 가는 물건이라
애초에 대형폐기물 신고 대상이 아니다.

그런데 `build_fee_stats.py`가 이 행들을 형광등 페이지에 붙여 **3,000원(5지역)**
이라고 표시하고 있었다. 형광등 램프에 수수료가 붙은 셈이다. 조명 계열 토큰을
LED등 페이지로 보내 바로잡았다. 형광등 페이지의 수수료 블록은 사라졌고,
LED등이 2,500원(23지역)을 받는다.

## 5. 이번 회차 산출물

```
품목       161 -> 164   (LED등 880, 모기장 505, 밥상 265)
개명         1          호일 -> 은박지 (255 -> 1,395)
별칭 회수    3          led등, 모기장, 밥상/교자상
수수료 매핑  1          조명 계열 -> LED등
```

발행 SQL은 `db/publish_164.sql`이다.

## 6. 남은 것

  페이지의 별칭도 언젠가 재야 한다. 뒤집힐 확률은 낮지만 영양제 사례가
  그랬듯 확률이 낮은 것과 없는 것은 다르다
- **전기매트를 다음 회차에 다시 잰다.** 2.61배가 커지면 개명이다
- 새로 붙인 별칭(LED등의 방등, 거실등, 평판등 / 모기장의 원터치, 캠핑)도
  다음 재측정 대상 풀에 들어간다. 페이지를 낳은 별칭이 또 페이지를 낳는다
